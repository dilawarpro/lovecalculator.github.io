The quick guide

What is the FLAMES game?

FLAMES is a classic paper-and-pencil game that has been played at school and in group chats for years. You take two names, cross out the letters they share, and use the number of letters left to find one of six words: Friends, Love, Affection, Marriage, Enemies or Siblings.

It is a game of spelling and counting, nothing more. It does not know anything about you or the other person, so enjoy it as a bit of fun.

How to play FLAMES step by step

  1. 1
    Write both names

    Use lowercase and ignore spaces. First names are the most common choice.

  2. 2
    Cross out common letters

    Cancel each letter that appears in both names, one for one. A letter can only cancel one match in the other name.

  3. 3
    Count the letters left

    Add up all the letters not crossed out, from both names. Call that number N.

  4. 4
    Remove letters from FLAMES

    Count N around F, L, A, M, E, S and remove the letter you land on. Start the next count from the letter after it and keep going until one letter remains.

  5. 5
    Read the last letter

    That letter is your FLAMES result. See the table below for what it means.

What does each FLAMES letter mean?

LetterMeaning
FFriends: an easy, fun bond.
LLove: the romantic result.
AAffection: warm feelings and care.
MMarriage: the happy-ever-after result.
EEnemies: a playful rivalry.
SSiblings: like brother and sister. Some versions say Sister.

Treat every result as a joke. Getting Enemies with someone you adore says nothing about your relationship.

Worked example: Alex + Sam

  • Cross out. Alex and Sam share one a. Cross it out and you are left with l, e, x and s, m.
  • Count. That is 5 letters, so N is 5.
  • Remove. Counting 5 around F L A M E S removes E. Counting 5 from S removes M, then S, then L, then A.
  • Result. The letter left is F, so Alex + Sam is Friends.

FLAMES tips for fair results

  • Pick one style. First names, full names and nicknames all give different answers, so use the same style every time.
  • Count repeats carefully. If one name has two e's and the other has one, only one pair is crossed out.
  • Ignore spaces and capitals. “Mary Jane” is the same as “maryjane”.
  • Keep the count going. After each removal, start counting from the next letter, not from F again.
  • Play together. FLAMES is more fun in a group chat than alone.

FLAMES calculator FAQs

What does FLAMES stand for?

F is Friends, L is Love, A is Affection, M is Marriage, E is Enemies and S is Siblings. Some versions use Sister for S.

How does the FLAMES game work?

Cross out the letters two names share, count the letters that are left, then use that number to remove letters from F-L-A-M-E-S one at a time until a single letter remains.

Is the FLAMES calculator accurate?

No. FLAMES is a paper-and-pencil party game that only looks at spelling. It cannot tell you anything real about a relationship.

Should I count repeated letters?

Yes. Each letter cancels only one matching letter in the other name. If one name has two e's and the other has one, a single e is crossed out and the extra e stays.

Can the same two names give a different FLAMES result?

Yes, if people play slightly different rules, such as using full names instead of first names or skipping repeated letters. With the method on this page, the same two names always give the same result.

Does this page give a FLAMES result automatically?

No. The calculator on this page gives the LoveCalcu name match percentage, not a FLAMES letter. Use the step-by-step guide to work out FLAMES yourself.
